# 2026 校赛选题三：高精度数控恒流源

队名：做的都队

本仓库用于整理高精度数控恒流源项目的方案设计、PCB 工程、调试记录、参考工程、数据手册和协作说明。项目目标是完成一个由 MCU 数控设定、硬件模拟环快速稳流、Buck 慢速调节功耗余量的恒流源系统。

## 项目概览

### 系统结构

```text
35V 输入
├── 可调 Buck：输出 VOUT+，给负载和低边 MOS 恒流功率级供电，目标范围约 5~30V
└── 固定 Buck：输出 5V
    ├── 串口屏
    ├── OPA197 运放
    └── LDO：输出 3.3V
        ├── STM32
        ├── DAC8562
        ├── TS5A3159A 模拟开关
        └── 比较器 / ADC 参考相关小信号电路
```

### 控制思路

```text
用户设定 Iset
    ↓
MCU 通过 DAC8562 CH2 输出 DAC_ISET = Iset * Rs
    ↓
模拟开关接通后，OPA197 + MOS + Rs 构成硬件恒流环
    ↓
MCU 采样 Vsense、VOUT+、VOUT-，计算 Iactual、Vload、VMOS
    ↓
MCU 慢速调整 DAC8562 CH1，改变可调 Buck 输出，控制 MOS 压降与发热
```

本项目把控制拆成三个层级：

| 层级 | 主要器件 | 作用 | 响应速度 |
| --- | --- | --- | --- |
| 硬件恒流环 | OPA197、MOS、2Ω 采样电阻 | 直接稳定输出电流 | 毫秒级或更快 |
| Buck 余量控制环 | STM32、DAC8562 CH1、LMR16030 | 调节 VOUT+，降低 MOS 发热 | 约 50~200ms 更新 |
| 校准 / 显示 / 保护 | STM32 ADC、串口屏、按键 | 显示、告警、状态机、后期校准 | 软件周期决定 |

## 关键参数

| 项目 | 当前设计 / 记录 |
| --- | --- |
| 采样电阻 | `Rs = 2Ω`，建议 0.1%、低温漂、2W 以上，优先 Kelvin 采样 |
| 目标电流关系 | `Iout = DAC_ISET / 2Ω` |
| 过流阈值 | `Vsense > 1.10V`，约等于 `Iout > 550mA` |
| 可调 Buck 近似关系 | `VOUT ≈ 30.98 - 10 * VDAC_CH1`，实测后需重新拟合 |
| MOS 余量 | `VMOS = VOUT- - Vsense`，自动调节目标约 2~4V |
| 负载电压 | `Vload = VOUT+ - VOUT-` |
| 负载电阻估算 | `Rload = Vload / Iout` |

## 调试注意事项

1. 使能 `BUCK_EN` 前必须确认 `DAC_CH1` 不是 `0V`。当前设计里 `DAC_CH1 = 0V` 对应可调 Buck 最大输出目标，误使能可能让 MOS 管承受过大功耗。
2. 初期调试建议使用实验室电源单通道输入，从 `9~12V`、低电流、低功率负载开始，不直接测试满量程。
3. 低压阶段先验证 `5V`、`3.3V`、DAC、模拟开关和手动 Buck，再做恒流环测试。
4. 自动 Buck 控制应在手动 Buck、恒流环、ADC 采样和保护逻辑都确认正常后再开启。
5. 高压阶段需要重新实测并拟合 `VOUT = A - B * VDAC_CH1`，不要只依赖电阻标称值推导。
6. 短路保护可以自动恢复；过流和开路保护建议锁存，等待用户按 `ALARM CLEAR` 后回到待机状态。

- 早期恒压源测试记录显示：输入电压、占空比上限、自举电路和采样运放异常需要重点关注；后续测试建议从更保守的电压、电流和负载组合开始。

## 推荐阅读顺序

1. 先看 `README.md`，了解仓库内容和文件关系。
2. 再看 `方案说明.md`，理解完整硬件与软件控制方案。
3. 调试前看 `调试流程.md`，按当前测试顺序推进。
4. 遇到 Buck / 电源异常时回看 `测试记录/恒压源测试/markdown/`。
5. 需要查器件参数时看 `数据手册/`。
6. 需要协作提交时看 `github协作指南/`。
