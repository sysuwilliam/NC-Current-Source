# 建议、测试计划与思路整理

## 命名规范

为了避免越说越晕，提议我们约定一下命名规范，不能什么都叫“实际值”，比如按下表

| 名字                      | 含义                                | 来源                             | 用途                             |
| ------------------------- | ----------------------------------- | -------------------------------- | -------------------------------- |
| `I_set`                 | 用户设定电流                        | 编码器/按键/程序                 | 用户目标                         |
| `DAC2_cmd`              | 软件最终给 DAC2 的命令电压          | 校准公式算出                     | 控制恒流目标                     |
| `I_meas`                | 电流表实测电流                      | 外部电流表                       | 校准真值、验收真值               |
| `ADC_VSENSE_raw`        | ADC 原始采样码                      | STM32 ADC                        | 校准底层数据                     |
| `I_serial`              | 目前串口未经最终校准/滤波的电流显示 | 软件旧公式                       | 临时观察，最后被 `I_disp`替代  |
| `I_disp`                | 最终成品上的显示电流                | 校准+滤波后                      | LCD/串口显示、用户看到的实际电流 |
| `I_fast`                | 快速保护用电流                      | 短平均、少滤波                   | 过流保护                         |
| `VOUTP_meas`            | 万用表测 VOUT+                      | 万用表                           | 校准/验证                        |
| `VOUTN_meas`            | 万用表测 VOUT-                      | 万用表                           | 计算 Vload、Vmos                 |
| `VOUTP_adc / VOUTN_adc` | MCU 根据 ADC 算出的 VOUT+/VOUT-     | ADC                              | 软件计算                         |
| `Rload_disp`            | 显示负载电阻                        | 软件计算+滤波                    | 发挥项显示                       |
| `Vmos`                  | MOS 两端电压                        | `VOUT- - Vsense`或万用表直接测 | Buck 外环、热安全                |

## 系统思路整理

### 1.电流控制主链：

`I_set → DAC2_cmd → 模拟恒流环 → I_meas`

解释：利用I_set和I_meas的数据，拟合出软件校准公式①，修正原本的 `I_set*2=DAC2_cmd` 公式，使 `I_set=I_meas`

### 2.电流显示链：

重要性：直接影响显示电流的精度；且因为这个数据作为pid的目标值，故间接影响输出电流的精度

`ADC_VSENSE_raw → I_serial → 校准公式② → 滤波 → I_disp`

解释：利用I_serial和I_meas的数据，拟合出软件校准公式②，修正原本的 `ADC_Vsense_raw /2 =I_disp` 公式，使 `I_disp=I_meas`

### 3.PID/PI ：

* 为了不影响硬件内环、不引入抖动，pid需要慢速调控DAC2
* 先做PI就够
* 一个思路

  ```
  每 100ms~500ms：
  error = I_set - I_disp
  如果误差持续存在：
  DAC2_cmd += 很小的修正量
  ```

## 三大保护逻辑

### 1.过流保护

看 I_disp 超过 550 就关 Buck EN

AI建议：不要用很慢的显示滤波值，而用 `I_fast`（短平均后的电流），这样既避免毛刺误触发，也不会保护太慢。

### 2.短路保护

注意：题目里的短路保护不是“短路就立刻断电”，而是“输出端短路时，自动限制输出电流为设定值，不损坏设备”

也就是0Ω时系统仍要正常运行，关键在于可调buck（mos）

0Ω/0500mA/Vmos留1V余量——则VOUT+需要1~2V——理论上可行，但我们没测过能否做到这一点

### 3.开路保护

开路时不要用 `Rload = V/I` 去判断，因为 I≈0，R会溢出或变成巨大数

AI建议方案：

```
如果 I_set > 某个阈值，比如 10mA
但 I_disp 长时间 < I_set 的 10% 或 < 5mA
同时 VOUT+ 已经升到较高值 / Buck 已经给到上限
则判断开路
```

或更简单的初版：

```
I_set > 20mA
且 I_disp < 2mA
持续 500ms
→ 开路报警
```

## 电流纹波问题（目标是0.2mA内）

这个到时候不知道怎么测评，示波器电流探头吗？

我们用万用表的话可以观察到0.01mA档的跳变（总体在0.1mA以内吧），但AI说明：万用表 0.01mA 档跳动小，不等于纹波 ≤0.2mA。万用表显示的是低速平均/有效值，可能看不到高频纹波。

AI建议：

```
用示波器电压探头测 Rs 两端电压纹波
AC耦合
尽量短地线
带宽限制打开，比如 20MHz
测 Vpp
I_ripple ≈ V_ripple / 2Ω
```

## 【建议】Rload 显示方案（当前优先级不高）

题目只是说“可测量并显示负载电阻值”，没有给很严格的精度。所以我们不用显示到小数点后三位。

AI的精度建议：

```markdown
0~10Ω：显示 0.1Ω
10~50Ω：显示 0.5Ω 或 1Ω
低电流时：Rload 不更新或显示“--”
```

因为低电流时，`I_disp` 在分母，轻微波动会把 Rload 放大得很明显。

处理方式：

```
VOUT+ / VOUT-：做 ADC 校准 + 中等滤波
I_disp：用校准后电流
Rload_disp：强滤波 + 显示死区
```
