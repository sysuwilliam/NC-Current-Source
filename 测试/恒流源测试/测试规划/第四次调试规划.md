附：

安全初始化和安全关断（AI提供的示例代码）

（这个优先级最高，避免上电瞬间 Buck 冲高、COM 存电、SW_IN 误接入）
```

void Safe_Init(void)

{

  Buck_Set(0);

  Swin_Set(0);

  DAC_Set_CH1(2.6f); // Buck 低输出目标，大约 5V

  DAC_Set_CH2(0.0f); // Iset = 0

}

void Safe_Off(void)

{

  DAC_Set_CH2(0.0f);

  HAL_Delay(20);

  Swin_Set(0);

  Buck_Set(0);

}
```

串口打印换算关系公式
```

VOUT+ = ADC_VOUT+\_pin \* 11

VOUT- = ADC_VOUT-\_pin \* 11

Vsense = ADC_VSENSE_pin

Iactual = Vsense / Rs

Vload = VOUT+ - VOUT-

VMOS = VOUT- - Vsense

Rload_est = Vload / Iactual
```
