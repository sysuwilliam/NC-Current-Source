## 摘要

本项目设计并实现了一套高精度数控恒流源系统，目标是在可调负载条件下输出稳定、可设定、可显示并具备保护能力的直流恒流。原理图采用 `STM32F103 + MCP4822 + OPA197 + MOS + 可调 Buck` 的总体结构，其中 MCP4822 的一路 DAC 输出电流参考，OPA197、低边 MOS 与 `2Ω` 采样电阻构成快速硬件恒流内环；STM32 采样 `Vsense`、`VOUT+` 和 `VOUT-`，计算输出电流、负载电压、负载电阻和 MOS 压差余量，并通过 MCP4822 的另一路 DAC 慢速调节 Buck 输出，使恒流环保留足够余量且降低 MOS 发热。现有测试表明，电流主链路线性良好，去掉 `0mA` 点后 `I_set -> I_meas` 拟合 `R² = 0.99999900`，`500mA` 点误差约为 `-0.5%`。后续重点是补全 `VOUT±` 校准、负载电阻显示、Buck 自动慢环和三类保护的最终验证。

## 1. 系统设计

### 1.1 总体架构

系统以外部直流输入作为整机能源，分为功率输出、模拟恒流、数字控制和人机交互四个部分。当前仓库中的设计资料和固件均围绕“硬件恒流内环 + 软件 Buck 余量外环”展开。

```text
35V 输入
├── 输入保护与滤波：保险丝、TVS、共模电感和输入电容
├── 可调 Buck：输出 VOUT+，给负载和低边 MOS 恒流功率级供电
└── 固定 Buck：输出 5V
    ├── 串口屏
    ├── OPA197 运放
    └── SPX29302 LDO：输出 3.3V
        ├── STM32F103
        ├── MCP4822 双通道 SPI DAC
        └── ADC / 比较器相关小信号电路
```

控制链路为：

```text
用户设定 Iset
    -> STM32 计算 DAC2 目标电压
    -> MCP4822 电流参考通道输出
    -> OPA197 + MOS + Rs 构成硬件恒流环
    -> STM32 采样 Vsense / VOUT+ / VOUT-
    -> 计算 Iactual / Vload / Rload / VMOS
    -> MCP4822 Buck 控制通道慢速调节可调 Buck 输出 VOUT+
```

### 1.2 关键器件与作用

| 模块     | 器件/参数                              | 作用                                                  |
| -------- | -------------------------------------- | ----------------------------------------------------- |
| 主控     | STM32F103C8T6 模块                     | 采样、计算、按键与串口屏交互、保护状态管理            |
| DAC      | MCP4822-E/SN                           | 双通道 SPI DAC，一路设定恒流参考，另一路控制可调 Buck |
| 运放     | OPA197ID 两颗                          | 一颗用于恒流环驱动 MOS，另一颗用于 Buck 反馈控制链路  |
| 功率调整 | SUD50N06-09L-TP 低边 MOS               | 线性调整输出电流，承担恒流功率级压差                  |
| 电流采样 | `Rs = 2Ω`                           | 将输出电流转换为采样电压                              |
| Buck     | LMR16030 两路                          | 一路固定 5V，一路输出可调 `VOUT+`                   |
| LDO      | SPX29302                               | 将 5V 转换为 3.3V，供 MCU 与小信号电路使用            |
| 输入保护 | RXEF090、SMBJ40A、SMBJ6.0A、ACM4520 等 | 输入过流、瞬态浪涌和共模噪声抑制                      |
| 交互     | 串口屏、按键、编码器                   | 设置电流、显示状态、清除报警                          |

恒流功率路径为：

```text
VOUT+ -> 负载 -> MOS -> Rs -> GND
```

该路径需要短而粗，MOS、采样电阻和 Buck 电感是主要发热器件。PCB 设计中应把 MOS Drain 大焊盘铺铜并多打过孔，外壳对应 MOS、Rs 和电感区域预留散热孔。

### 1.3 PCB 与可靠性设计

1. `Rs` 使用 Kelvin 采样：功率电流从采样电阻主焊盘流过，运放反馈和 ADC 采样从采样点单独引出，减少铜皮压降对电流精度的影响。
2. `GND` 与 `AGND` 单点连接：连接点放在 Rs 下端或 `AGND_STAR` 附近，避免 Buck、屏幕和数字回流流过模拟参考地。
3. Buck 与模拟区隔离：Buck 的 SW 节点、电感、二极管和输入输出电容远离 DAC、OPA、ADC 分压和 MOS Gate 信号。
4. `VOUT+ / VOUT-` 采样从真实负载端附近引出，用于计算负载电压、负载电阻、MOS 压差和保护状态。
5. 外壳作为加分项处理：正文只放最终装配图、散热孔设计和接口布置说明；完整三维源文件放仓库附录。

## 2. 控制分析

### 2.1 硬件恒流内环

硬件恒流内环由 `DAC2 -> OPA197 -> MOS -> Rs` 构成。DAC2 输出电压作为运放同相端参考，运放调节 MOS Gate，使采样电阻上的电压接近参考电压。理想关系为：

```text
Iout = Vref / Rs
Iout = DAC_ISET / 2Ω
```

该环路不依赖软件高速闭环，主要由运放和 MOS 的模拟响应决定，因此适合承担快速稳流任务。实测中 `DAC2_meas -> I_meas` 拟合为：

```text
I_meas_mA = 0.497253 * DAC2_mea_mV - 0.029041
R² = 0.99999994
RMSE = 0.041 mA
```

该结果说明只要 DAC2 实际输出电压确定，模拟恒流内环线性非常好。当前主误差更多来自 DAC 命令值、ADC 显示换算和 Buck 余量设置。

### 2.2 Buck 慢速余量外环

Buck 外环的目的不是直接高速调电流，而是给恒流内环提供合适压差，避免 MOS 压差过小导致恒流失败，也避免压差过大造成 MOS 发热。

核心计算量为：

```text
Vload = VOUT+ - VOUT-
Rload = Vload / Iout
VMOS = VOUT- - Vsense
VOUTP_target = I_set * Rload_est + I_set * Rsense + VMOS_margin
```

根据测试和分析，初版可取：

```text
Rsense = 2Ω
VMOS_margin = 1.2V ~ 2.0V
```

DAC1 与 Buck 输出的反算采用当前测试总结中的关系：

```text
VOUT+ = 10.012879 * DAC1_actual_V - 1.797554
DAC1_cmd_V = (VOUTP_target + 1.797554) / 10.012879
```

仓库早期测试记录中也出现过 `VOUT+ = 31.242 - 10.011 * V_DAC1` 的负斜率公式，二者对应的控制点或电路阶段可能不同。最终报告应以最后一晚实测的 `DAC1_cmd -> VOUT+` 标定为准，明确写出当时测量点、接法和公式符号。

同时必须加入限幅，避免 Buck 输出超过硬件和输入电源能力。当前 `VOUT± 校准 -> Rload 校准 -> Buck 自动调 DAC1` 仍属于最终待验证项，建议最后一晚按以下顺序补齐：

1. 用万用表标定 `VOUT+`、`VOUT-` 显示值。
2. 用校准后的 `Vload / Iout` 计算 `Rload_est`。
3. 固定 50mA、250mA、500mA 三档，改变负载，观察自动 Buck 是否能让 `VMOS` 保持在目标范围。
4. 记录 `DAC1_cmd`、`VOUT+`、`VOUT-`、`VMOS` 和 MOS 温升趋势。

### 2.3 显示、状态与交互层

STM32 负责把 ADC 采样值换算为显示量，并通过串口屏显示工作模式、设定电流、实际电流、负载电阻、DAC 输出和保护状态。按键与编码器负责：

1. 设定目标电流。
2. 开启或停止输出。
3. 在过流或开路故障后清除报警。

显示值不应直接作为保护判断的唯一依据。报告中区分：

| 名称           | 用途                             |
| -------------- | -------------------------------- |
| `I_serial`   | ADC 原始换算电流                 |
| `I_disp`     | 校准和滤波后的用户显示电流       |
| `I_fast`     | 短平均、低延迟的保护判断电流     |
| `Rload_disp` | 滤波和死区处理后的负载电阻显示值 |

## 3. 保护逻辑

保护逻辑分为过流、短路和开路三类。报告应如实记录每一类保护的状态：已实现、已验证、设计完成待验证。当前建议最终报告采用下表更新。

| 保护类型 | 判据                                                                            | 动作                                             | 恢复方式                          | 当前状态             |
| -------- | ------------------------------------------------------------------------------- | ------------------------------------------------ | --------------------------------- | -------------------- |
| 过流保护 | `Vsense > 1.10V` 或 `I_fast > 550mA`，持续超过去抖时间                      | `SW_IN=0`、`DAC2=0`、`BUCK_EN=0`，报警锁存 | 用户按 `ALARM CLEAR` 后回到待机 | 设计完成，待最终验证 |
| 短路保护 | `Iset` 非零、`Iactual` 接近设定值且 `Vload < 0.2V ~ 0.5V` 持续 50ms-200ms | 进入短路限流，降低 Buck 输出，显示“短路限流”   | 短路解除后自动回到正常 Buck 调节  | 设计完成，待最终验证 |
| 开路保护 | `Iset > 20mA`、`Iactual < 5mA`，Buck 已升高仍无电流，持续约 200ms           | `SW_IN=0`、`DAC2=0`、`BUCK_EN=0`，报警锁存 | 接好负载后人工清除报警            | 设计完成，待最终验证 |

过流和开路应锁存，防止故障解除瞬间自动重启造成反复冲击；短路保护以“限流不损坏”为目标，可以自动恢复。保护判断使用 `I_fast` 或短时间平均值，避免显示滤波过慢造成保护滞后。

## 5. 误差分析

### 5.1 DAC2 命令值与实际输出误差

`DAC2_meas -> I_meas` 的线性非常好，而 `DAC2_cmd -> I_meas` 的 RMSE 明显更大，说明模拟恒流内环本身不是主要误差来源，DAC 命令值到实际电压的偏差和软件换算更关键。现已采用前馈校准：

```text
DAC2_cmd_mV = (I_set_mA - 1.368386) / 0.498188
```

低电流段仍受零点偏置和仪表分辨率影响，`0mA`、`5mA`、`10mA`、`20mA` 可单独补测。

### 5.2 采样电阻误差与温漂

理想公式假设 `Rsense = 2Ω`。实际中采样电阻的初始精度、温漂、焊盘热分布和功率发热都会改变等效阻值。建议使用 `0.1%`、低温漂、足够功率裕量的采样电阻，并在最终报告中记录测试时电流档位、持续时间和发热情况。

### 5.3 ADC 分压与参考误差

`VOUT+`、`VOUT-` 经分压进入 ADC，误差来源包括分压电阻容差、ADC 参考电压、布线噪声和滤波延迟。当前已得到校准式：

```text
VOUTP_cal = 0.985864 * VOUTP_serial + 0.001825
VOUTN_cal = 0.998639 * VOUTN_serial - 0.026753
```

后续 `Rload` 和 `VMOS` 都应使用校准后的 `VOUTP_cal`、`VOUTN_cal` 计算，否则 Buck 慢环会被错误余量带偏。

### 5.4 Buck 余量不足

主表中 `300mA ~ 450mA` 的 `VMOS` 估算值只有 `0.178V ~ 0.616V`，说明 Buck 目标电压偏低，MOS 压差不足，恒流环可能接近饱和。改进方向是用校准后的负载估计值计算：

```text
VOUTP_target = I_set * Rload_est + I_set * Rsense + VMOS_margin
```

并让 DAC1 慢速调节 Buck，使 `VMOS` 保持在目标范围。

### 5.5 纹波测量误差

若目标电流纹波为 `0.2mA`，在 `2Ω` 采样电阻上的等效电压纹波只有：

```text
0.2mA * 2Ω = 0.4mVpp
```

这已经接近普通示波器探头和接地方法的噪声底。最终纹波测试必须先测噪声底，再使用短地、限带和合适时基记录，不应只用一次 `5mVpp` 普通探头读数下结论。
